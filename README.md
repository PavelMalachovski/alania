# alania

Telegram-бот воронки продаж для эксперта: прогрев аудитории, презентация услуг,
приём заявок на консультацию и менторство, выдача бесплатного гайда-лид-магнита
и рассылки по базе подписчиков.

## Возможности

- **Главное меню** — навигация по услугам и материалам (inline-кнопки).
- **Личная работа** — консультация «Точка сборки» и менторство: описание,
  «кому подойдёт», как проходит сессия, отзывы с пагинацией, оплата в ₽/€.
- **Заявка** — пошаговая анкета (имя → запрос → контакт), заявка сохраняется в
  БД, всем админам приходит уведомление с профилем клиента.
- **Гайд-лид-магнит** — «Карта твоего запроса» отдаётся файлом прямо из бота.
- **Игра VECHNOST** и **бесплатный Telegram-канал** — ссылки-переходы.
- **Аналитика воронки** — каждое нажатие кнопки пишется в таблицу `events`.

### Команды

Публичные:

- `/start` — приветствие и главное меню
- `/id` — узнать свой Telegram ID

Админские (только для ID из `ADMIN_IDS`):

- `/admin` — список админ-команд
- `/set_guide` — загрузить файл гайда (бот запомнит его и будет отдавать всем)
- `/broadcast` — рассылка сообщения всем пользователям (с превью и подтверждением)
- `/cancel` — отменить текущее действие

## Стек

- Python 3.12, [aiogram 3.x](https://docs.aiogram.dev/)
- SQLAlchemy 2.0 (async) + asyncpg, PostgreSQL
- Docker, хостинг на [Railway](https://railway.app/)

## Локальный запуск

```bash
pip install -r requirements.txt
cp .env.example .env   # заполнить значения
python main.py
```

### Переменные окружения

| Переменная     | Описание                                                        |
| -------------- | --------------------------------------------------------------- |
| `BOT_TOKEN`    | Токен бота от [@BotFather](https://t.me/BotFather)              |
| `ADMIN_IDS`    | Telegram ID админов через запятую (`111,222`). Узнать — `/id`   |
| `DATABASE_URL` | Строка подключения к PostgreSQL                                 |
| `TZ`           | Часовой пояс, напр. `Europe/Prague`                             |

## Деплой на Railway

1. Подключить репозиторий — Railway соберёт образ по `Dockerfile`.
2. Добавить PostgreSQL и прокинуть `DATABASE_URL=${{Postgres.DATABASE_URL}}`
   (бот сам приведёт `postgresql://` к `postgresql+asyncpg://`).
3. Задать `BOT_TOKEN`, `ADMIN_IDS`, `TZ`. Таблицы создаются автоматически при
   старте.

После первого запуска:

- Каждый админ (включая владельца бота) должен открыть бота и нажать `/start` —
  иначе бот не сможет присылать ему уведомления о заявках.
- Загрузить файл гайда командой `/set_guide` — до этого кнопка «Забрать гайд»
  работает по резервной ссылке.

## Структура проекта

```
main.py              точка входа: бот, middleware, роутеры
database.py          модели (User, Lead, Setting, Event) и подключение к БД
filters.py           IsAdmin — доступ к админ-командам
middlewares.py       безопасные колбэки + логирование событий
handlers/
  start.py           /start, /id, главное меню
  lead.py            FSM-заявка на консультацию/менторство
  consultation.py    экраны личной работы (консультация, менторство, отзывы)
  info.py            игра, канал, гайд
  admin.py           /set_guide, /broadcast, /admin
keyboards/
  inline.py          все inline-клавиатуры и внешние ссылки
Dockerfile           образ python:3.12-slim
```
