# Лендинг «Апертуры» — запись на консультации

Дата: 2026-07-29
Статус: спека утверждена, реализация не начата

## Задача

Продающая страница для холодного трафика (Instagram, реклама). Единственная
цель — довести человека до записи на консультацию. Запись целиком остаётся
в Telegram-боте: страница прогревает и передаёт, ничего не бронирует сама.

## Решения, принятые на брейншторме

| Вопрос | Решение |
|---|---|
| Что делает CTA | Deep-link в бота `https://t.me/alania_sky_bot?start=site` |
| Своя запись на сайте | Нет. Слоты, холд, оплата, перенос уже работают в боте |
| Аудитория | Холодный трафик, Лану не знает |
| Фото | Одно, это Лана. Работает как единственный визуальный акцент |
| Хостинг | Vercel, Root Directory = `web/`, без сборки |
| Язык, обращение | Русский, на «ты» (как в боте) |

## Визуальное направление: «Апертуры»

На исходном фото Лана снята **через проём в полке**: тёплый вольфрамовый свет,
ночная комната, рама на переднем плане. Страница воспроизводит эту логику.

Фото — единственный слой `position: fixed; inset: 0` во всю высоту вьюпорта.
Секции-«апертуры» вырезают его через `clip-path: inset(...)` на контейнере
(`clip-path` на предке клиппит `fixed`-потомка — это и даёт эффект окна на
неподвижный кадр). При прокрутке в каждой апертуре видно свой фрагмент одного
и того же снимка. Так единственное фото используется 3–4 раза и ни разу не
повторяется.

Апертур ровно три: герой, «Обо мне» (вертикальная), «Цена и запись» (широкая
летербокс). Больше — размывает приём.

### Палитра (снята с кадра)

| Токен | Hex | Роль |
|---|---|---|
| `--ink` | `#100C09` | фон страницы, тёплый почти-чёрный |
| `--ember` | `#1E1611` | подложка секций |
| `--wood` | `#B8834E` | дерево полки: хайрлайны, рамки апертур |
| `--glow` | `#E8B87C` | янтарный свет: CTA, акценты |
| `--linen` | `#F2E7D8` | основной текст |
| `--ash` | `#8A7A6C` | вторичный текст, подписи |
| `--slate` | `#5B7A7A` | единственный холодный акцент (бирюзовая коробка на полке) — только видимый фокус клавиатуры |

Палитра намеренно многоцветно-тёплая, а не «чёрное + один неон».

### Типографика — шрифт кодирует, кто говорит

- **Golos Text** (400/500/600/800) — голос Ланы и весь интерфейс. Родная
  кириллица, не переведённая латиница. Заголовки крупные, тихие,
  трекинг −0.03em.
- **Prata** (400) — голос клиенток: отзывы и одна выносная строка в герое.
- Служебные подписи — Golos Text 500, капс, трекинг +0.14em.

Шрифты подключаются с Google Fonts (`display=swap`), фолбэки — системные.

### Движение

Проявление секций на 8px + fade по `IntersectionObserver`. Больше ничего:
эффект апертур создаётся самой прокруткой. `prefers-reduced-motion: reduce`
отключает проявление полностью.

## Структура страницы

1. **Шапка** — имя «Лана Леонович» и кнопка записи, проявляется только после
   ухода героя за верхний край.
2. **Герой** — апертура с фото + тезис
   «Разговор, после которого видно, где ты сама себя останавливаешь».
   Подзаголовок про интегративный подход (психосоматика, телесная терапия,
   коучинг, глубинная психология). Строка `70 МИНУТ · ОНЛАЙН · 100 € / 10 000 ₽`.
   CTA + подпись, что выбор времени и оплата происходят в боте.
   Цена показана в первом экране осознанно: на холодном трафике скрытая цена
   даёт отказ ниже по странице.
3. **С чем приходят** — три области дословно из `handlers/consultation.py`:
   отношения с собой / отношения с другими / реализация. **Без нумерации** —
   это зоны, а не этапы, порядок не несёт информации.
4. **Как проходит** — 70 минут, видеозвонок, и честная механика записи:
   время из реального свободного календаря, бронь держится 30 минут
   (`BOOKING_HOLD_MINUTES`), перенос не позже чем за сутки
   (`RESCHEDULE_THRESHOLD`).
5. **Обо мне** — вертикальная апертура во всю высоту секции. Образование и
   методы, лет практики, число сессий, короткий личный абзац.
6. **Голоса** — 7 отзывов из `REVIEWS`, набраны Prata. Первый целиком,
   остальные короткие, в две колонки разной длины. Без звёзд и рейтингов,
   подпись «клиентка».
7. **Цена и запись** — широкая апертура, повтор CTA, рубли или евро.
8. **Вопросы** — как выбрать время, как оплатить, перенос, часовые пояса
   (Прага / Мск), конфиденциальность, что если формат не подойдёт.
9. **Подвал** — для не готовых платить сегодня: бесплатный канал
   (`CHANNEL_URL`) и тест «Кто управляет твоей жизнью?» — оба ведут в того же
   бота. VECHNOST (`GAME_URL`) мелкой строкой: она не про эту цель.
   Личка Ланы (`DM_URL`).

## Содержание, которого ещё нет

Заполняется владельцем, в вёрстке стоят явно помеченные заглушки
(`data-placeholder`), которые нельзя выкатывать в прод:

- формулировка образования, методов, сертификатов;
- лет практики (число);
- число проведённых сессий (число).

Эти три места собраны в блоке «Обо мне» и вынесены отдельным комментарием в
`index.html`, чтобы их было видно одним поиском.

## Реализация

- `web/index.html` — вся страница одним файлом: разметка + `<style>` + минимум
  `<script>` (шапка на скролле, `IntersectionObserver`, аккордеон вопросов).
  Без сборки, без зависимостей, без фреймворка.
- `web/assets/lana.jpg` — фото (кладёт владелец).
- Ссылки берутся из `keyboards/inline.py` и не расходятся с ботом:
  бот `https://t.me/alania_sky_bot?start=site`, личка `t.me/LanaLeonovich`,
  канал и игра — как в `CHANNEL_URL` / `GAME_URL`.
- Цена — `100 € / 10 000 ₽`, совпадает с `formatting.PRICE_TEXT`.

## Качество

- Адаптив до 360px: на мобильном апертуры становятся полноширинными,
  двухколоночные блоки схлопываются в одну колонку.
- `clip-path` + `position: fixed` на iOS Safari проверяется отдельно; фолбэк —
  обычный `background-size: cover` без эффекта окна, страница остаётся целой.
- Видимый фокус клавиатуры (`--slate`), контраст текста к фону не ниже
  WCAG AA.
- `prefers-reduced-motion` уважается.
- Осмысленные `<title>`, `meta description`, Open Graph (превью в мессенджерах
  критично: страницу будут кидать ссылкой).

## Явно вне объёма
