# Улучшения бота: запросы, крипто-оплата, оферта, сообщения от Ланы

Дата: 2026-08-03 · Ветка: `feature/bot-improvements-aug`

Пять точечных изменений в Telegram-боте. Сайт правится параллельной веткой —
здесь только бот.

## 1. Блок «С какими запросами я работаю»

`handlers/consultation.py`, константа `PERSONAL_WORK_TEXT`. Три строки-маркера
заменяются на четыре категории с жирными подзаголовками, стиль маркера `●`
сохраняется:

```
<b>С какими запросами я работаю:</b>
● <b>Эмоциональная сфера и психофизиология:</b> панические атаки, фоновая
  тревожность, гиперконтроль, эмоциональное выгорание, депрессивные состояния
  и упадок сил.
● <b>Самооценка и идентичность:</b> синдром самозванца, жёсткая самокритика,
  поиск себя, выход из повторяющихся деструктивных сценариев.
● <b>Отношения и границы:</b> сложности в коммуникации, зависимые паттерны,
  страх проявленности и конфликтов.
● <b>Реализация и автономия:</b> потеря ориентиров, сложности в принятии
  решений, переход на новый уровень доходов и пробивание «стеклянного потолка».
```

## 2. Перенос «Я оплатил(а)» на новую строку

`handlers/booking.py`, `cb_book_slot`. Было `Оплати удобным способом и нажми
«✓ Я оплатил(а)» ⇩` одной строкой — становится:

```
Оплати удобным способом и нажми
«✓ Я оплатил(а)» ⇩
```

## 3. Оплата в криптовалюте

Отдельный экран, чтобы не раздувать экран оплаты.

**Константы** (`formatting.py`): `CRYPTO_ADDRESS = "TWCyAwzPrnevmWPei4RdreuQCXbDD6JXhh"`,
`CRYPTO_AMOUNT_TEXT = "116 USDT · сеть TRC20"`.

**Клавиатуры** (`keyboards/inline.py`):
- `booking_pay_kb()` — добавляется кнопка «Оплатить в криптовалюте» →
  `pay_crypto:<booking_id>`;
- новая `booking_crypto_kb(booking_id)` — «⧉ Скопировать адрес» (нативная
  `copy_text`, Bot API 8.0), «✓ Я оплатил(а)» → `paid_crypto:<booking_id>`,
  «⇦ Назад» → `pay_back:<booking_id>`, «Написать в ЛС».

**Хендлеры** (`handlers/booking.py`):
- `cb_pay_crypto` — проверяет, что бронь принадлежит вызывающему и всё ещё
  `held`; редактирует экран: слот, сумма, адрес в `<code>` (тап-копирование как
  запасной путь для старых клиентов), предупреждение про сеть TRC20 и комиссию
  на стороне отправителя, строка про Дисклеймер;
- `cb_pay_back` — возврат на экран оплаты (перерисовывает тот же текст, что
  `cb_book_slot`, — общая функция `_pay_screen_text(slot, hold_local)`);
- существующий `cb_paid` принимает оба колбэка (`paid:` и `paid_crypto:`), из
  префикса определяется способ оплаты. Разница только в тексте уведомления
  Лане: «Проверь оплату в Tribute» либо «Проверь поступление USDT (TRC20)» —
  иначе она не поймёт, где искать деньги. В БД способ не храним: уведомление
  уже ушло, а статусная машина от способа не зависит.

`requirements.txt`: `aiogram>=3.15,<4.0` (ради `copy_text`).

## 4. Юридический блок перед выбором оплаты

Добавляется в конец текста экрана оплаты, перед клавиатурой:

```
—> Нажимая кнопку «Оплатить», вы подтверждаете, что вам исполнилось 18 лет,
вы ознакомились и полностью принимаете условия Публичной оферты, Политики
конфиденциальности и Информированного согласия.
(При выборе оплаты криптовалютой также применяются условия Дисклеймера
по крипто-платежам).
```

Названия документов — гиперссылки. URL живут одним блоком в
`keyboards/inline.py` рядом с остальными внешними ссылками:

```python
SITE_URL = "https://alania.sky"          # TODO: реальный домен сайта
LEGAL_OFFER_URL = f"{SITE_URL}/oferta"
LEGAL_PRIVACY_URL = f"{SITE_URL}/privacy"
LEGAL_CONSENT_URL = f"{SITE_URL}/consent"
LEGAL_CRYPTO_URL = f"{SITE_URL}/crypto-disclaimer"
```

Домен — заглушка по решению владельца: правится одной строкой, когда
параллельная ветка сайта выкатит страницы. На крипто-экране повторяется только
строка про Дисклеймер.

## 5. Сообщения Ланы всем — над сердечком

Голосовые и текст рассылка уже умеет: `/broadcast` копирует сообщение через
`copy_message`, который переносит любой тип контента. Не хватает только
порядка в чате — сейчас сообщение падает под 🤍-якорь и приветственный экран,
а нужно, чтобы оно встало между историей и сердечком.

Механика: после доставки сообщения пользователю бот пересобирает низ чата —
`reset_keyboard()` (удалить старый якорь, прислать новый 🤍 с клавиатурой) и
`show_screen(MAIN_MENU_TEXT)` (удалить прежнее окно, прислать приветствие).
Итоговый порядок: `… → сообщение Ланы → 🤍 → приветствие`.

Побочный эффект принят осознанно: если клиент в этот момент читал раздел, он
увидит вместо него меню. Рассылка редкая, а низ чата важнее.

Отправок на пользователя становится 3 вместо 1 → пауза в цикле поднимается
0.05 → 0.15 с, чтобы не упереться в лимит Telegram (~30 сообщений/сек).
Ошибки пересборки глотаются: недоставленная рассылка уже посчитана в `failed`,
падать из-за якоря цикл не должен.

## Тесты

`tests/`, поверх существующей фейковой сессии:
- крипто-экран: `pay_crypto:<id>` на чужой/не-`held` брони не открывается, на
  своей — показывает адрес и кнопку копирования;
- `paid_crypto:<id>` переводит бронь в `pay_claimed` и шлёт админу
  уведомление с пометкой USDT;
- `pay_back:<id>` возвращает экран оплаты;
- рассылка: после `broadcast_confirm` пользователю уходит копия сообщения,
  затем якорь и приветствие — проверяется порядок вызовов.

## Вне объёма

- Сайт и страницы юр. документов (параллельная ветка).
- Автоматическая проверка крипто-платежей по блокчейну — оплата
  подтверждается Ланой вручную, как и Tribute.
- Хранение способа оплаты в БД.
