# Лендинг

Статическая страница для холодного трафика. Единственная цель — довести
человека до записи. Сама запись остаётся в боте: страница никуда не ходит,
ничего не бронирует и не имеет бэкенда.

Спека и обоснование решений: `docs/superpowers/specs/2026-07-29-landing-page-design.md`.

## Что нужно доделать перед деплоем

1. **Абсолютные адреса в Open Graph.** В `<head>` заменить `og:image` и
   добавить `og:url` с реальным доменом — иначе превью в мессенджерах
   не соберётся.

## Незаполненное в блоке «Обо мне»

Личного абзаца, лет практики, числа сессий и образования пока нет. Разметка
для них написана, но выключена атрибутом `hidden`: на странице показывается
только то, что правда есть, — имя и абзац про подход. Сейчас в блоке одна
колонка вместо двух, и это выглядит намеренно.

Как появятся тексты: найти `data-placeholder` (пять мест), вписать реальное
и снять `hidden` — с абзаца в `.about__text` и с колонки цифр и образования.
Бирюзовая рамка на заглушках оставлена нарочно: если `hidden` снимут раньше,
чем впишут текст, это будет видно с первого взгляда.

## Локальный просмотр

```bash
python -m http.server 4321 --directory web
```

## Деплой на Vercel

vercel.com → Add New → Project → импорт `PavelMalachovski/alania` →
**Root Directory: `web`**, Framework Preset: Other, команда сборки пустая.
Остальное по умолчанию.

Заголовки кеширования лежат в `vercel.json` рядом. Фото отдаётся на сутки
с `stale-while-revalidate`, а не «навсегда»: имя файла не содержит хеша,
и с immutable замена снимка не доехала бы до тех, кто уже был на странице.

## Фотография

Исходник (3600×4500, 8,4 МБ) пережат в `assets/lana.webp` (108 КБ) и
`assets/lana.jpg` (314 КБ), 1600×2000. В разметке `<picture>`: webp с
jpg-фолбэком. Если фото меняют — пережимать так же, иначе первый экран
на мобильном будет грузиться секундами.

Кадрирование задаётся переменной `--film-pos` у апертуры: `50% 45%` в герое,
`50% 74%` у широкой перед ценой. Плёнка растянута на вьюпорт по ширине, а
фото портретное — горизонтального запаса нет, поэтому крутить имеет смысл
только второе число.

Апертур две. Третья, узкая щель в «Обо мне», была в замысле и не пережила
проверки на настоящем снимке: в фокусе там только сама Лана, и вырезка по
любому краю кадра давала размытое пятно.

## Известное расхождение с ботом

Ссылки в подвале ведут в бота с параметрами `?start=quiz` и `?start=channel`,
но `cmd_start` в `handlers/start.py` payload сейчас не разбирает: человек
попадёт на главный экран, а не сразу в тест или на канал. Разделы доступны
с нижней клавиатуры, так что тупика нет, но обещание карточки не выполняется
буквально. Чинится небольшой правкой в боте — разбором `command.args`.
