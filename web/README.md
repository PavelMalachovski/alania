# Лендинг

Статическая страница для холодного трафика. Единственная цель — довести
человека до записи. Сама запись остаётся в боте: страница никуда не ходит,
ничего не бронирует и не имеет бэкенда.

Спека и обоснование решений: `docs/superpowers/specs/2026-07-29-landing-page-design.md`.

## Что нужно доделать перед деплоем

1. **Положить фото** в `web/assets/lana.jpg`. Без файла апертуры показывают
   тёплый градиент-заглушку — страница не ломается, но ради фото она и сделана.
2. **Заполнить четыре заглушки** в блоке «Обо мне». Ищутся одним поиском по
   `data-placeholder`: личный абзац, лет практики, число сессий, образование.
   Заглушки подсвечены бирюзовой рамкой — если рамка видна на проде, значит
   что-то забыли.
3. **Абсолютные адреса в Open Graph.** В `<head>` заменить `og:image` и
   добавить `og:url` с реальным доменом — иначе превью в мессенджерах
   не соберётся.

## Локальный просмотр

```bash
python -m http.server 4321 --directory web
```

## Деплой на Vercel

Новый проект → импорт этого репозитория → **Root Directory: `web`**,
Framework Preset: Other, команда сборки пустая. Всё остальное по умолчанию.

## Подстройка кадра в апертурах

Фото портретное, а плёнка растянута на вьюпорт по ширине — горизонтального
запаса у неё нет. Поэтому кадрирование задаётся вертикально, переменной
`--film-pos` у каждой апертуры (`50% 42%` — герой, `50% 24%` — щель в «Обо мне»,
`50% 74%` — широкая внизу). Если после подстановки настоящего фото Лана
оказалась срезана — крутить второе число.

## Известное расхождение с ботом

Ссылки в подвале ведут в бота с параметрами `?start=quiz` и `?start=channel`,
но `cmd_start` в `handlers/start.py` payload сейчас не разбирает: человек
попадёт на главный экран, а не сразу в тест или на канал. Разделы доступны
с нижней клавиатуры, так что тупика нет, но обещание карточки не выполняется
буквально. Чинится небольшой правкой в боте — разбором `command.args`.
