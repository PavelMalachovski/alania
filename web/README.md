# Лендинг

Статическая страница для холодного трафика. Единственная цель — довести
человека до записи. Сама запись остаётся в боте: страница никуда не ходит,
ничего не бронирует и не имеет бэкенда.

Спека и обоснование решений: `docs/superpowers/specs/2026-07-29-landing-page-design.md`.

## Вторая версия страницы

Страница переписана по макету «Лендинг v2»: заголовки набраны Prata (серифом),
цена показана открыто в трёх местах (герой, таблица «Как проходит», финальный
блок) — кнопки «Узнать стоимость» больше нет, финальный призыв вынесен на
светлую (`--linen`) плашку, а тест переехал в конец страницы и стал последним
экраном перед подвалом.

Блока «Обо мне» с заглушками (`data-placeholder`) больше нет: его содержание
переехало в раздел «Как я работаю» — четыре инструмента и рамка «Чего на
сессии не будет». Если понадобятся цифры практики и образование, это новый
блок, а не восстановление старого.

Ответы теста хранятся в `localStorage` под ключом `alania_quiz_v2`: человек
может уйти со страницы и вернуться на том же вопросе. «Прервать» и «Пройти
заново» чистят состояние. Вопросы и пороги результата — из `quiz_data.py`,
менять их надо в обоих местах.

## Локальный просмотр

```bash
python -m http.server 4321 --directory web
```

## Деплой на Vercel

vercel.com → Add New → Project → импорт `PavelMalachovski/alania` →
**Root Directory: `web`**, Framework Preset: Other, команда сборки пустая.
Остальное по умолчанию.

Заголовки кеширования лежат в `vercel.json` рядом. Фото отдаётся на сутки
с `stale-while-revalidate`, а не «навсегда»: имя файла не содержит хеша,
и с immutable замена снимка не доехала бы до тех, кто уже был на странице.

## Фотография

Исходник (3600×4500, 8,4 МБ) пережат в `assets/lana.webp` (108 КБ) и
`assets/lana.jpg` (314 КБ), 1600×2000. В разметке `<picture>`: webp с
jpg-фолбэком. Если фото меняют — пережимать так же, иначе первый экран
на мобильном будет грузиться секундами.

Апертура во второй версии одна — в герое. Кадрирование задаётся переменной
`--film-pos`: `50% 45%` на десктопе, `50% 40%` под 900px. Фото портретное
(4:5), горизонтального запаса нет — крутить имеет смысл только второе число.
Широкая апертура перед финальным призывом убрана: на светлой плашке она
разрезала блок пополам.

## Известное расхождение с ботом

Ссылки ведут в бота с параметрами `?start=site`, `?start=channel` и
`?start=quiz_result`, но `cmd_start` в `handlers/start.py` payload сейчас
не разбирает: человек попадёт на главный экран, а не сразу на канал или
к записи. Разделы доступны с нижней клавиатуры, так что тупика нет, но
обещание карточки не выполняется буквально. Чинится небольшой правкой
в боте — разбором `command.args`.
